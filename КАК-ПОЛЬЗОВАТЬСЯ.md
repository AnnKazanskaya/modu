# modu — сайт модульных диванов

## Как открыть сайт
ES-модули (Three.js) и видео **не работают**, если просто открыть файл двойным щелчком.
Нужен локальный сервер. Самый простой способ:

1. Открой «Терминал».
2. Вставь команду и нажми Enter:
   ```
   cd ~/Desktop/modu && python3 -m http.server 8123
   ```
3. Открой в браузере: **http://localhost:8123**
4. Чтобы остановить сервер — в Терминале нажми `Ctrl + C`.

## Как добавить свои фото
Просто положи файлы с такими именами в папку **assets/photos/** —
они появятся на сайте сами (пока файла нет, видна серая заглушка):

| Имя файла              | Где появится                          |
|------------------------|---------------------------------------|
| `room.jpg`             | большое фото в галерее (комната)      |
| `texture.jpg`          | вертикальное фото (рука на ткани)     |
| `studio.jpg`           | угловая сборка                        |
| `detail.jpg`           | деталь / шов                          |
| `carved.jpg`           | **блок-переход «сруб»** с надписью modu |

Формат — `.jpg`. Если хочется `.png`, скажи мне, поменяю.

## Видео и логотип
- Видео на главной: `assets/hero.mov` (это твой `sofa.mov`).
- Логотип нарисован кодом (SVG) — его не нужно подкладывать.

## Что умеет конструктор (страница «Собрать диван»)
- 12 цветов ткани, 3 материала (букле / лён / велюр);
- 2–5 модулей, 0–6 подушек, подлокотники, кушетка (L-форма);
- ножки: в пол / цилиндр / конус / куб + высота;
- размеры ползунками **или перетаскиванием цветных точек** прямо на 3D-модели;
- вращение мышкой, кнопка «Сохранить картинку».

## Файлы
- `index.html` — главная
- `constructor.html` + `js/constructor.js` — 3D-конструктор
- `css/style.css`, `css/constructor.css` — оформление
- `js/main.js` — анимация появления блоков
